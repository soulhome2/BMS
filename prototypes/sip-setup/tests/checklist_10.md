# Проверенное поведение прототипа — модель 10

Снимок на **2026-09-29**: 186 проверок в 26 разделах, провалов нет.

Перечень того, что `index_10.html` действительно делает: каждую строку проверяет
`run_10.js`, прогоняя страницу в jsdom и нажимая на элементы так же, как это делал бы
администратор. Модель — из документа «10 - Модель географии, помещений и панелей»:
страна как адресный корень с профилем, элементы адреса одного типа с видом из профиля,
объект обслуживания вне адреса, помещение с типом, номером-строкой и кодом вызова,
панель с местом, уровнем и зоной обслуживания, исключения из зоны вместо списка связок.

Прогон — так же, как для `run.js` (см. `../README.md`, раздел «Поведенческие проверки»),
с другим файлом:

```
node run_10.js path/to/index_10.html
```

На Node 22 до 22.12 нужен флаг `--experimental-require-module` (новый jsdom — ES-модуль).
Прогону хватает 1,2 ГБ памяти; на машине с небольшим объёмом ОЗУ его стоит запускать с
потолком `--max-old-space-size=1200`, чтобы при сбое упал только он.
