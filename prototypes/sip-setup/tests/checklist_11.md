# Проверенное поведение прототипа — модель 11

Снимок на **2026-09-29**: 118 проверок в 21 разделе, провалов нет.

Перечень того, что `index_11.html` действительно делает: каждую строку проверяет
`run_11.js`, прогоняя страницу в jsdom и нажимая на элементы так же, как это делал бы
администратор. Развитие `index_10.html` на той же модели; в этой версии:

- вкладок «Адреса / Оборудование» нет: слева один навигатор мест, над ним две
  закреплённые кнопки — «Все панели» и «Все аккаунты» с числами по области видимости;
- обе таблицы сделаны одним компонентом: поиск, фильтры по состоянию, объекту и дому,
  сортировка, страницы, выделение и массовые действия; «объект → его панели» — это
  фильтр таблицы панелей, а не отдельная вкладка;
- карточка дома разбита на вкладки «Помещения · Панели · Параметры», подъезда —
  «Помещения · Панели»; первой открываются помещения, выбранная вкладка запоминается;
- удаление больше 20 учётных записей — через окно со сводкой (что, где, какие объекты
  уйдут) и вводом числа; после подтверждения остаётся отсчёт с «Отменить»;
- отсчёт отмены замирает, пока на уведомление навели или перешли к нему с клавиатуры
  (WCAG 2.2.1);
- у склеенной строки навигатора нет флажка: удалилось бы только последнее звено;
- объекты обслуживания — своя ветка навигатора: первая строка корня «Объекты
  обслуживания» → объект (его карточка и дома, подписанные с улицей) → дом; из дома,
  открытого так, «назад» ведёт к объекту, а не к улице; ссылка на объект из карточки
  дома и панель территории из поиска тоже переводят навигатор к объекту;
- длинные списки везде идут страницами: списки карточки — по 25, таблица помещений —
  по 50 с заголовком этажа на каждой странице («— продолжение», если этаж разорван
  границей), окна выбора — по 50 с «Отметить все найденные — N», поиск слева — по 50
  без прежней обрезки на 200, уровни навигатора — по 50. Поиск, фильтр и смена уровня
  или карточки возвращают на первую страницу.

Проверки карточек (коды вызова, зоны, пикеры) и фильтров таблиц здесь выборочные —
по одному-два сценария на каждую возможность, без перебора всех вариантов. Страницы
уровня навигатора отдельно не проверены: в демо-наборе нет уровня длиннее 50 строк,
пейджер у навигатора тот же, что у поиска слева.

Прогон — как для `run.js` (см. `../README.md`, раздел «Поведенческие проверки»),
с другим файлом:

```
node run_11.js path/to/index_11.html
```

На Node 22 до 22.12 нужен флаг `--experimental-require-module` (новый jsdom — ES-модуль).
