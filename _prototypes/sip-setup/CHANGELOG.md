# Изменения прототипа

Записи от новых к старым. Каждая запись отвечает не «что поправили», а «какое
доменное решение за этим стоит» — это и есть польза файла при переносе в ТЗ.

## 2026-08-07

- Поведение не менялось. Прототип переехал в `_prototypes/sip-setup/index.html`,
  рядом появился чек-лист проверенного поведения; npm-обвязка убрана, зависимости
  в хранилище больше не держим.

## 2026-08-06

- Адрес получил три уровня над ЖК: регион → город/село → ЖК. Страна одна (РФ),
  поэтому в дереве её нет.
- ЖК стал контейнером для нескольких домов: подписка, тариф и лимиты живут на ЖК,
  дом — только адресный уровень.
- Email перестал быть уникальным в установке: один человек владеет квартирами в
  разных домах одного ЖК, поэтому уникальность проверяется только внутри квартиры.
  В карточке аккаунта показаны другие квартиры того же владельца.
- Сохранение состояния в браузере отключено (`PERSIST = false`): страница всегда
  открывается с демо-данными заново.
- Начальная ширина панели дерева в десктопном режиме выравнивается по правому краю
  переключателя ЖК.

## 2026-08-05

- Статус регистрации SIP стал полем только для чтения, появилась кнопка «Проверить
  статус». Источник истины — Kamailio, UI его не выдумывает.
- Realm убран из карточек: он единый на установку и задаётся SIPManager.
- Появилась блокировка учётки как отдельное действие; в провижининг она уходит как
  `subscriber/delete`, разблокировка — как `subscriber/create`.
- Удаление объектов, состояние которых уехало в Kamailio, больше не отменяется через
  undo. Вместо этого отложенная фиксация: объект помечен, идёт отсчёт, до его конца
  удаление можно отменить. Undo остался для локальных правок (связки, переименования).
- Добавлены клиентские валидации: формат и уникальность SIP-номера, формат email.
- Пароли показаны под маской с кнопками «показать» и «скопировать».
- Карточка ЖК описывает арендатора: договор, тариф, статус и срок подписки, лимиты и
  их расход. Исчерпанный лимит блокирует создание квартир и панелей, проблемная
  подписка помечается в дереве и в переключателе ЖК.

## 2026-08-04

- Двойная навигация («Адреса» и «Панели» как два дерева) заменена на переключатель ЖК
  в шапке плюс одно дерево с фильтрами вида «Адреса» / «Оборудование». Для режима
  «Все ЖК» добавлена табличная сводка по парку панелей.
- Нативные `<select>` заменены на стилизованные комбобоксы.

## 2026-08-03

- Первая версия: оформление и навигация перенесены с эталона `groups.html` —
  дерево с поиском и контекстными меню слева, карточка объекта справа, тосты,
  модальные окна, разделитель панелей.
